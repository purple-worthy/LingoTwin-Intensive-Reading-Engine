# 插件化双栏逐词精读电子书 Skill (v4.0)

## 1. 插件式微内核架构 (Plugin Architecture)
前端引擎暴露全局注册中心 `window.ReaderPlugins.register(pluginConfig)`，新增功能严禁修改主框架代码，只需挂载插件对象：
- `id`: 插件唯一标识
- `slot`: 挂载插槽位置（`'toolbar'` | `'setting-panel'` | `'footer'`）
- `render(ctx)`: 返回 DOM 节点或 HTML 字符串
- `onArticleChange(article, ctx)`: 每次切换章节或翻页时的生命周期钩子

## 2. Setting 设置中心规范
所有视觉与交互偏好统一收纳于右上角 `⚙️ Setting` 抽屉面板：
1. **排版样式 (Theme)**：`样式1: 黑灰绿` | `样式2: 真经暗红` | `样式3: 暖纸护眼`
2. **显示样式 (View Mode)**：
    - `1. 单页面显示（上下滚动）`：垂直自然流式布局，适合连续阅读与打印。
    - `2. 双页面显示（左右滚动）`：横向分页视口（支持鼠标滚轮横向翻页、键盘左右方向键翻页及翻页按钮）。
3. **词汇解析深度**：`全词详尽版（含虚词/基础词）` | `仅核心高频词`

## 3. 整本电子书（如《小王子》）分章处理契约
- 支持用户直接选择本地 `.txt` 整本电子书文件。
- 前端自动按章节正则（如 `Chapter \d+` / `^[IVXLC]+\.` / 空行分段）切分为独立章节存入目录树。
- 每次仅针对**当前阅读的单章**向 AI 请求 JSON 精读数据（遵循 `tokens` + `vocabulary` 结构），避免上下文超限与输出截断。
