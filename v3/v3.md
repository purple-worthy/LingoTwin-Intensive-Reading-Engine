# 雅思双栏逐词精读数据提取 Skill (v3.0)

## 1. 核心架构红线 (Strict Architecture Boundary)
- **数据与视图彻底解耦**：前端 HTML/CSS/JS 渲染引擎已固定存在。当用户提供文章或要求抓取文章时，**严禁生成、重写或追加任何 HTML 标签（如 `<div>`, `<ruby>`, `<style>`）**。
- **确定性输出契约 (Deterministic Output)**：你的唯一交付物是一个**合法的、可直接复制的纯 JSON 代码块（` ```json ... ``` `）**，用于注入前端渲染引擎的 `ARTICLES_DB` 数组中。

## 2. 交互界面与渲染引擎规范（供构建/维护前端壳子时遵循）
若需初始化或升级前端 HTML 引擎，必须严格满足以下 UI 布局：
1. **左上角极简折叠目录**：页面左上角仅保留一个紧凑的目录图标按钮（`☰`），默认收起不占空间；点击后平滑滑出简洁的抽屉式文章目录列表。
2. **多源导入弹窗面板**：顶部工具栏提供 `📥 导入/解析文章` 按钮，打开后包含三个 Tab：
    - **Tab 1（立即可用）**：直接粘贴英文文章文本框 + 填入生成的 JSON 数据一键渲染。
    - **Tab 2（预留接口）**：输入网址从网上抓取内容（当前标注 `目前由 Agent 端抓取后传入`）。
    - **Tab 3（预留接口）**：打开本地 `.txt / .md / .epub` 文件（预留 `<input type="file">` 节点）。
3. **双档词汇详解模式**：支持在前端一键切换 **`全词解析模式`（基础阶段：连介词、冠词、代词和所有实词全部给出词性与释义）** 与 **`核心词模式`（进阶阶段：仅展示高频核心词汇）**。
