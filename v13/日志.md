## 二、 核心评估：tencent/Hy-MT2-1.8B-GGUF 接入 Ollama 的实战价值
你下载的 tencent/Hy-MT2-1.8B-GGUF（腾讯混元 2026 年 5 月开源的第二代专用机器翻译模型，18 亿参数量级）对你当前这个项目具有极高的实用价值，甚至可以说比通用 qwen3:4b 更契合翻译场景。

1. 它好在哪里？（为什么比通用 4B/8B 模型更适合本项目）
   极致的推理速度与低显存占用：1.8B 参数量在 Q4/Q8 量化下仅占约 1.1 GB ~ 1.8 GB 显存/内存，在消费级显卡或现代 CPU 上的吐字速度是 4B 模型的 2~3 倍，是 8B 模型的 4~5 倍，几乎做到“秒级直出段落译文”。

专用翻译对齐（拒绝废话与幻觉）：它是专门针对机器翻译（MT）任务训练的专用模型，原生支持上下文语境翻译、术语干预和格式保留翻译，不会像通用聊天模型那样动辄输出长篇 <think> 思考链或客套废话。

2. 它能直接作用在你的项目中的哪些功能上？（具体场景举例）
   整章与单段极速英译汉（⚡ 词库秒配 + Ollama 续译未译段）：

场景举例：在精读《芒果街上的小屋》或外刊长文时，以前用 4B/8B 模型翻译 20 段可能需要等一两分钟；换成 Hy-MT2-1.8B 后，每段译文几乎 0.5~1 秒刷出，彻底解决你之前觉得“本地翻译太慢、容易被打断”的痛点。

生僻词 / 网络新词的语境补全（词典兜底引擎）：

场景举例：当你在新加的“独立查词页”输入 stardict（2018 年停更词库）里查不到的 2025–2026 年新词或短语（如 agentic workflow、vibe coding）时，系统自动调用 Hy-MT2-1.8B 生成精准中文释义并存入 MySQL。

双语对照与格式保留翻译（Structured Translation）：

场景举例：官方针对 Hy-MT2 专门优化了带有定界符/结构化标签的翻译能力，非常契合你把整段带标点的英文交给它直接输出对应中文。

3. 如何把下载的 Hy-MT2-1.8B-GGUF 导入 Ollama？
   假设你下载的文件名为 Hy-MT2-1.8B-Q4_K_M.gguf，只需在同级目录新建一个无后缀的文本文件 Modelfile，写入以下三行配置（使用官方推荐的零废话翻译指令模板）：

Dockerfile
FROM ./Hy-MT2-1.8B-Q4_K_M.gguf
PARAMETER temperature 0.1
SYSTEM "Translate the user's text into fluent Simplified Chinese. Output ONLY the translated result without any explanation."
然后在终端执行一条命令即可注册进 Ollama（注册后在网页 Setting -> 连接探测 下拉框里就能直接选中它）：

Bash
ollama create hy-mt2:1.8b -f Modelfile
## 三、 实现“HTML 打开自动拉起 Python + HTML 关闭自动退出”
因为浏览器网页出于安全限制不能在打开瞬间直接执行本地 .exe 或 .py 文件，在 Windows（结合你使用的 IntelliJ IDEA 2026.1.4）中，实现“打开即启动、关闭即退出”的完全体闭环方案如下：

打开联动（两种方式任选其一）：

方式 A（IDEA 内部运行）：保持你之前配置的 Before launch -> Start MySQL Bridge (start_bridge.vbs)，在 IDEA 点运行 HTML 时自动无黑框拉起 mysql_bridge_server.py。

方式 B（桌面双击独立运行）：创建一个 启动知语精读引擎.bat（放在 HTML 和 mysql_bridge_server.py 同级目录）：

DOS
@echo off
start "" /B pythonw mysql_bridge_server.py
timeout /t 1 /nobreak >nul
start "" "lt_reader_v13.html"
(注：pythonw 是 Windows 自带的 Python 无窗口后台运行程序，双击这个 .bat 会静默拉起后台服务并立刻用默认浏览器打开网页)。

关闭联动（已内置在下方 v13.0 后端与前端中）：

网页打开后每 3 秒自动向后端发送 /api/heartbeat 心跳；当你关闭浏览器标签页或整个浏览器窗口时，触发 pagehide 信标发送 /api/shutdown
（且有 10 秒看门狗兜底），后台 pythonw.exe / python.exe 会自动退出，绝不残留。
