## 关键决策（不可漂移）

1. 笔记 key = 单词小写归一化；中英文词都可记
2. IndexedDB 是主存储（离线可用、快），MySQL 是备份（防丢）；写入时双写，MySQL 失败不阻断本地保存
3. 读取优先 IndexedDB；若本地无但 MySQL 有，回填本地（换浏览器不丢）
4. renderDictResultCard 是同步函数 → 笔记区用「同步渲染占位 + 异步 fetch 填充」避免改动所有调用点
