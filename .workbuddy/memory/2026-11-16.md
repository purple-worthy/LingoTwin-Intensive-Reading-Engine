## 追加：v14.3 · 插件开关状态持久化

**现象**：「段落同步滑动释义窗」每次打开页面都变回关闭。

**根因**（经典的状态覆盖 bug，不是缺字段）：
`plugins.enabled` 一直有、`toggle()` 也写了；但 bootstrap 恢复插件后，`applyLoadedPreferences` 调用
`applyVocabLayout('auto', card, true)`，旧实现里 `mode !== 'para-slider'` 就**无条件**置 `states=false` 并 `LocalDB.put(enabled:false)`
→ 每次开页清一次，自我强化。

**五条原则**：单一真相源 / 写穿 / 恢复期只读 / 默认值只在从未有记录时用 / 状态别挂 window 绕过闭包。

**改动**
- 主程序：`isSliderPluginEnabled()`、`disableSliderPlugin()`、`applyVocabLayout` 加 `skipSave` 守卫、
  `ReaderApp.setVocabLayout()`、`Object.defineProperty(window,'vocabLayoutPref')` 代理兼容旧插件、`toggle()` 改 upsert + 同步 prefs
- 插件：`onEnable/onDisable` 改调 `app.setVocabLayout()`

**验证**：抽真实函数跑 4 种时序（插件开+恢复auto / 插件关+prefs残留 / 用户主动切换 / MySQL二次恢复），全部符合预期。

**待用户操作**：库里现存 `enabled:false`（bug 期间写坏），需手动打开一次做播种。
